# Changelog

## 1.0.0

First public release as **one-for-all-switch**.

- Deskflow keyboard/mouse sharing coordinated with DDC/CI monitor input switching.
- Configurable route hotkey and explicit switching without screen-edge handoff.
- Host/client setup, LAN discovery, reconnect and managed input-process recovery.
- Windows login startup, client keep-awake and elevated-window compatibility options.
- Optional brightness synchronization, disabled by default.
- Correct handling of an absent Windows startup task (0x80070002).
- Existing `%LOCALAPPDATA%\KvmSwitch` configuration remains compatible.

Special thanks to the Deskflow developers and contributors.
